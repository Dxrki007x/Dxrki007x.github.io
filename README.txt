# Suchin AI — Gemini Chat

ไฟล์:
- index.html
- style.css
- script.js

วิธีใช้:
1. เปิด https://aistudio.google.com/app/apikey
2. สร้าง Gemini API Key
3. เปิด index.html
4. กด “ตั้งค่า API”
5. วาง API Key
6. กด “ทดสอบ Key”
7. กด “บันทึก”
8. เริ่มคุยกับ AI

หมายเหตุ:
โปรเจกต์นี้ใช้ Gemini REST API จาก browser โดยตรง จึงเหมาะกับการสาธิตในเครื่อง/งานเรียนเท่านั้น
อย่านำ API Key ไป commit ใน GitHub หรือฝังไว้ในเว็บไซต์สาธารณะ
